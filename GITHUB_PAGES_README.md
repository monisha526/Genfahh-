# Genfahh Team Portfolio — GitHub Pages

This project is configured for the repository `monisha526/Genfahh`.

## Publish
1. Extract this ZIP on your phone/computer.
2. Upload the **contents** of the extracted folder to the root of `https://github.com/monisha526/Genfahh` (not the ZIP itself).
3. Make sure `.github/workflows/deploy.yml` is included. On mobile, hidden folders can be hard to select; if it is missing, the automatic deployment will not run.
4. In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
5. Open the **Actions** tab and wait for “Deploy Genfahh to GitHub Pages” to finish successfully.
6. Open `https://monisha526.github.io/Genfahh/`.

The Vite base path is set to `/Genfahh/` for this repository. If you rename the repository, update the `base` value in `vite.config.ts`.
